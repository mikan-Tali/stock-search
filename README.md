# stock-search — 個別株スイングトレード提案ツール

投資信託をメインにしつつ、個別株（主に日本株）で **1〜3か月のスイングトレード** を行うための提案ツールです。
自動売買はせず、提案を見て自分で発注する前提です。

## 機能

| タブ | できること |
|---|---|
| 📊 ダッシュボード | 日経平均・TOPIX・S&P500・SOX・ドル円・VIX、地合い判定、保有の評価額・含み損益・本日損益（60秒ごと自動更新） |
| 💼 保有銘柄 | 保有銘柄の登録・編集・決済（SQLite に保存）、CSV インポート/エクスポート、ウォッチリスト |
| ⚡ リアルタイム | 保有＋ウォッチ銘柄の株価ボード（15秒〜5分間隔で自動更新）、損切り/目標到達・急騰落アラート、チャート（ローソク足・移動平均・ボリンジャー・RSI・MACD） |
| 🔍 分析・提案 | 保有銘柄ごとのアクション（継続/利確/損切り/買い増し/トレーリングストップ）、決算日の警告、ポートフォリオのレバレッジ・β・ボラティリティ・相関・集中度、個別銘柄の売買プラン（損切り・目標・推奨株数） |
| 🧭 スクリーナー | 東証プライム主要75銘柄＋ウォッチリストをスコアリングして候補を抽出 |
| 🧪 バックテスト | 「スコア○以上で買い→損切り/目標/期限で手仕舞い」が過去にその銘柄で機能していたかを検証 |
| 🤖 AI提案 | Claude が分析データ＋最新ニュース（Web検索）を踏まえて具体的な売買提案を作成（任意、APIキー必要） |
| 📒 売買記録 | 実現損益・勝率・プロフィットファクター・累積損益の推移 |

### 分析ロジックの概要

- **総合スコア（-100〜+100）**: トレンド（25日線/75日線の並びと傾き）、モメンタム（1か月・3か月騰落）、MACD、RSI、出来高急増を合算
- **セットアップ判定**: ブレイクアウト（52週高値付近＋出来高増）／押し目買い（上昇トレンド中の25日線付近）／リバウンド狙い
- **売買プラン**: 損切り = 現在値 − 2×ATR（直近20日安値も考慮）、目標1 = リスクの2倍、目標2 = リスクの3倍
- **株数**: 固定リスク法。「損切りに掛かった時の損失 ≦ 資金 × 許容リスク%」となる株数を100株単位で算出。1銘柄上限・レバレッジ上限・地合い係数（リスクオフ時は縮小）も反映
- **地合い**: 日経平均の50日線/200日線、VIX でポジションサイズ係数を調整

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。まずサイドバーで「個別株に回す資金」「1トレードの許容損失」を設定し、「💼 保有銘柄」で保有株を登録してください。

### AI提案を使う場合（任意）

```bash
export ANTHROPIC_API_KEY=sk-ant-...
streamlit run app.py
```

### 保存先

保有銘柄・売買記録・設定は `data/portfolio.db`（SQLite）に保存されます（Git 管理外）。
`STOCK_SEARCH_DB=/path/to/portfolio.db` で保存先を変更できます（Dropbox 等の同期フォルダに置くと複数 PC で共有可能）。

CSV でまとめて登録する場合の形式:

```csv
ticker,shares,avg_price,side,account,stop_loss,take_profit,memo
7203,100,2850,買い,特定口座,2700,3200,押し目買い
6857,100,9500,買い,NISA成長投資枠,,,
```

## 注意事項

- 株価は Yahoo Finance（yfinance）から取得しており、**東証銘柄は約15〜20分遅延** します。
  本当のリアルタイム株価が必要な場合は、証券会社の API（auカブコム証券の kabuステーション API、立花証券 e支店 API など）に
  `stock_search/market.py` の `MarketData` を差し替えてください。
- 本ツールの出力は情報提供であり、利益を保証するものではありません。投資判断はご自身の責任で行ってください。
